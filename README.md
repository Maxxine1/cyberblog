**Breaking things to learn how to secure them.**

## 🔍 What you'll find here

- Bug bounty writeups and lessons learned
- Vulnerability research and exploit analysis
- Tools and scripts in C, C++, Python and Bash
- Hardening tips and security fundamentals

##  Run it locally

```bash
git clone --recurse-submodules https://github.com/Maxxine1/cyberblog.git
cd cyberblog
hugo server -D
```

Then open http://localhost:1313

##  New post

```bash
hugo new content posts/my-post.md
```

Set `draft: false`, push to `main`, and GitHub Actions publishes it.
